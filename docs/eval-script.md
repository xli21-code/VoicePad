# VoicePad 对照集 · 录音脚本

目标：40 条真实口述，覆盖 8 类场景，用来横向评测 ASR 引擎、量 CER、测端到端延迟。

**录之前**
1. 菜单栏关掉 **Smart Polish / Translation**（现在润色还走 xl3049，一句要等 5 秒，录音期间不需要）。
2. 打开 TextEdit → 新建文稿 → 格式 → **制作纯文本**，光标放在里面。这篇就是"接收区"。
3. 每句单独一行：按住 `Left Control` → 说 → 松开 → 等字出来 → 回车。
4. **不要念标点**，不要念"第一、第二"（除非它本来就是句子里的词）。
5. 说错不要重录，让它错——我们要的是原始 ASR，不是正确答案。
6. 只有一种情况重录：粘出来是空的（说明这句没被识别到）。

预计 15–20 分钟。
